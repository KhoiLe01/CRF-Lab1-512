# CS 512 - Lab 1 - Khoi Le
This folder contains code written by Khoi Le for Lab 1. This folder contains code for problem 1c, problem 2, and problem 4.

This code is developed using Python 3.12.9. Virtual environment is suggested to run the code.
## Set up
Install virtual environment
```
py -m venv venv
```
Install required libraries using pip
```
pip install -r requirements.txt
```
## Run the code
The code should be run from the root directory to generate result in the correct folder.

Problem 1c:
```
python .\code\khoi\part1c.py
```
All the code for problem 2 are inside part2.py. This includes part a and b. Uncomment and comment the function at the bottom inside the file to test accordingly. To run code of problem 2:
```
python .\code\khoi\part2.py
```
Code for problem 4a and 4b are inside part4.py. User should change the argument 'mode' of the main function to test accordingly. Problem 4c is in part4_debug_and_4c.py. To run the code:
```
python .\code\khoi\part4.py
```
```
python .\code\khoi\part4_debug_and_4c.py
```
Comments are also available to help guiding through the code.
